Personal portfolio website live at **[saturnmade.tech](https://saturnmade.tech)**. Showcases projects, skills, and background for Spring 2027 software engineering internships and May 2027 new-grad roles.

---

## 🚀 Running Locally

```bash
git clone https://github.com/saturn-amarbat/personal-website.git
cd personal-website
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 🛠️ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** JavaScript
- **Styling:** Tailwind CSS
